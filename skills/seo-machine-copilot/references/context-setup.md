# Context Setup

Use these files to replace the reusable context that SEO Machine expects from the original Claude Code workspace.

## Required Context Files

Create these files inside `seo-machine/context/` in the target repository:

- `brand-voice.md` — tone, claims, positioning, forbidden phrases, audience expectations
- `style-guide.md` — formatting, capitalization, reading level, citation preferences, CTA style
- `seo-guidelines.md` — heading rules, metadata rules, keyword handling, linking expectations
- `features.md` — product features, service details, differentiators, proof points
- `internal-links-map.md` — URLs or repo references for pages to link from content
- `target-keywords.md` — primary keywords, secondary keywords, intent, priority clusters
- `competitor-analysis.md` — notable competitors, strengths, weaknesses, gaps to exploit
- `writing-examples.md` — examples of on-brand content to imitate

## Minimum Useful Content

Each file should contain project-specific facts rather than placeholders. Short, accurate notes are better than broad generic guidance.

At minimum:
- Brand voice should define tone and audience
- SEO guidelines should define title, description, heading, and link rules
- Internal links should include canonical page names and destinations
- Target keywords should group topics by business priority

## Maintenance Rules

- Update context files before starting a new campaign or content batch
- Treat context files as source-of-truth inputs, not generated outputs
- Review them whenever messaging, product positioning, or SEO strategy changes
