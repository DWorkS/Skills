# Specialist Agents

The original SEO Machine repo uses Claude agents. In this skill, preserve them as repeatable Copilot specialist passes.

## Auto-Run Specialist Passes After Writing

- **SEO Optimizer** — keyword placement, hierarchy, on-page SEO improvements
- **Meta Creator** — multiple title and meta description options
- **Internal Linker** — concrete internal linking recommendations with anchor text
- **Keyword Mapper** — keyword distribution, density, and topical coverage review

## Additional Specialist Passes

- **Content Analyzer** — orchestrates deeper scoring across search intent, keywords, readability, content length, and SEO quality
- **Editor** — style and clarity cleanup
- **Headline Generator** — CTR-focused headline alternatives
- **CRO Analyst** — CTA, offer, form, and trust-signal recommendations
- **Performance Analyst** — performance-led recommendations using analytics data
- **Landing Page Optimizer** — landing-page-specific SEO and CRO improvements

## Operational Rule

Treat these as named checkpoints in the workflow so outputs remain consistent even though the original Claude agent runtime is gone.
