# Analytics Pipeline

The original repo combines qualitative writing workflows with quantitative analysis. Preserve these analysis layers when data is available.

## Core Analysis Categories

1. search intent classification
2. keyword density and distribution
3. competitor length benchmarking
4. readability scoring
5. SEO quality scoring

## Extended Analysis Categories

- engagement analysis
- content scoring
- opportunity scoring
- above-the-fold analysis
- CRO checks
- CTA analysis
- competitor gap analysis
- landing-page scoring
- trust signal analysis
- trend and social research aggregation

## Opportunity Scoring Model

Preserve the original weighted model when prioritizing work:

- volume — 25%
- ranking position — 20%
- intent fit — 20%
- competition — 15%
- cluster fit — 10%
- CTR — 5%
- freshness — 5%
- trend — 5%

## Practical Use

If direct API integrations are unavailable, use exported CSV, JSON, Markdown, or spreadsheet summaries and ask Copilot to apply the same categories and weights.
