# Commands

Use these as named Copilot task patterns to replace the original Claude Code slash commands.

## Core Content Workflows

### `/research [topic]`
- create a research brief
- analyze keyword intent
- identify top competitors
- summarize content gaps
- propose outline, links, and metadata direction
- save under `research/`

### `/write [topic]`
- create a long-form article draft
- follow brand, style, SEO, and linking context
- include headings, CTA opportunities, and metadata
- save under `drafts/`
- follow with specialist passes

### `/article [topic]`
- create a simplified article workflow when full orchestration is unnecessary

### `/rewrite [topic]`
- refresh existing content using an audit or prior draft
- keep what works
- update structure, facts, links, and keyword coverage
- save under `rewrites/`

### `/optimize [file]`
- perform final SEO quality review
- return readiness score, issues, and quick wins
- save optimization output under `output/` or `drafts/`

### `/analyze-existing [url/file]`
- audit an existing page or article
- score health, freshness, structure, and conversion readiness
- save under `audits/` or `research/`

### `/publish-draft [file]`
- create publish-ready output
- package title, meta description, slug, excerpt, links, and CMS notes

### `/scrub [file]`
- remove repetitive AI patterns
- smooth phrasing and tone before publication

## Research and Strategy Workflows

- `/performance-review` — prioritize work using analytics exports
- `/priorities` — score topics or pages by opportunity
- `/cluster [topic]` — build a pillar and supporting-cluster plan
- `/research-serp` — SERP-first analysis
- `/research-gaps` — competitor gap review
- `/research-trending` — trend and freshness opportunities
- `/research-performance` — performance-led research
- `/research-topics` — topic expansion and clustering

## Landing Page Workflows

- `/landing-write`
- `/landing-audit`
- `/landing-research`
- `/landing-competitor`
- `/landing-publish`

These mirror the blog workflows but emphasize conversion structure, offer clarity, and trust signals.
