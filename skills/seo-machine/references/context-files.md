# Context Files

These files are the core operating inputs that make the skill reusable in any project.

## Required Files

- `brand-voice.md` — messaging pillars, tone, voice rules, prohibited phrasing, audience expectations
- `style-guide.md` — grammar, formatting, capitalization, citation, and structure rules
- `seo-guidelines.md` — title, meta description, heading, keyword, readability, and linking rules
- `features.md` — product, service, proof point, and differentiator reference
- `internal-links-map.md` — canonical pages, URLs, anchor text ideas, and topic clusters
- `target-keywords.md` — primary keywords, secondary keywords, intent, volume notes, and cluster mapping
- `competitor-analysis.md` — competitors, positioning, content strengths, weaknesses, and exploitable gaps
- `writing-examples.md` — examples of high-quality on-brand content
- `cro-best-practices.md` — conversion guidance for CTAs, offers, trust signals, and forms

## Priority Order

Highest priority:
1. brand voice
2. writing examples
3. internal links map
4. SEO guidelines
5. target keywords

## Operating Rules

- Keep context files factual and current.
- Treat them as hand-maintained source documents.
- Update them before major campaigns, product changes, or content strategy changes.
- Use repository-relative links when possible so Copilot can inspect the referenced material directly.
