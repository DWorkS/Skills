# Getting Started

Use this skill as the GitHub Copilot replacement for the original `TheCraigHewitt/seomachine` workspace.

## Quick Start

1. Create a `seo-machine/` directory in the target repository or map the skill onto an equivalent existing content workspace.
2. Copy the context templates from `templates/context/` into `seo-machine/context/`.
3. Fill the context files with real business information before generating content.
4. Create the lifecycle folders described in `repository-layout.md`.
5. Start with a research workflow before writing or rewriting content.

## Minimum Files to Prepare

- `seo-machine/context/brand-voice.md`
- `seo-machine/context/writing-examples.md`
- `seo-machine/context/internal-links-map.md`
- `seo-machine/context/seo-guidelines.md`
- `seo-machine/context/target-keywords.md`

## Recommended External Inputs

- GA4 exports
- GSC exports
- DataForSEO reports
- CMS exports
- existing top-performing or underperforming content

## First End-to-End Run

1. Run a research brief for a target topic.
2. Draft a long-form article.
3. Run specialist passes for SEO, meta, internal links, keywords, editing, and CRO.
4. Create the final optimization report.
5. Package the result for publication.
