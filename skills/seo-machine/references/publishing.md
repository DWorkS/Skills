# Publishing

The original repo publishes to WordPress and includes Yoast metadata support. Preserve the same output expectations even if the host project uses another CMS.

## Publication Package

Each publication-ready artifact should include:

- final article or landing page body
- title
- slug suggestion
- meta title options
- meta description options
- excerpt or summary
- internal link recommendations
- CTA placement notes
- optional CMS field mapping

## WordPress / Yoast Compatibility

When the target project uses WordPress:

- prepare content for WordPress block or Markdown import as required
- include Yoast-friendly title and description values
- provide any category, tag, or taxonomy notes the team uses

## Handoff Rule

If the skill does not directly publish, it must still leave behind a complete publishing package so a human or automation can publish with no missing SEO fields.
