# Repository Layout

Use this layout to preserve the original SEO Machine file-based workflow:

```text
seo-machine/
├── context/
├── topics/
├── research/
├── drafts/
├── rewrites/
├── published/
├── audits/
├── landing-pages/
├── output/
└── review-required/
```

## Directory Responsibilities

- `context/` — reusable operating context for brand, style, SEO, links, keywords, competitors, CRO, and examples
- `topics/` — raw topic ideas and backlogs
- `research/` — briefs, SERP reviews, competitor analyses, clustering work, and prioritization notes
- `drafts/` — in-progress article drafts plus generated optimization notes
- `rewrites/` — refreshed or updated versions of existing content
- `published/` — publication-ready or published content snapshots
- `audits/` — page or article audits and health reports
- `landing-pages/` — landing page drafts and audit artifacts
- `output/` — reports, summaries, and combined analysis exports
- `review-required/` — optional handoff stage before publishing

## Naming Guidance

- research briefs: `brief-<topic>-<date>.md`
- audits: `analysis-<topic>-<date>.md`
- drafts: `<topic>-<date>.md`
- rewrites: `<topic>-rewrite-<date>.md`
- optimization reports: `optimization-report-<topic>-<date>.md`
